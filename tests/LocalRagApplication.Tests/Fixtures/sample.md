# ローカルRAGアプリケーションについて

このドキュメントは、RAG（Retrieval-Augmented Generation）質問応答アプリケーションの概要をまとめたサンプルです。テストおよび動作確認用のfixtureファイルとして使用します。

## 主な機能

アプリケーションが提供する主な機能は次のとおりです。

- ファイルの取り込み（テキスト・Markdown・PDFに対応）
- 取り込んだファイルのチャンク分割と埋め込みベクトル化
- 質問文とチャンクの類似度検索
- 検索結果をもとにしたローカルLLMによる日本語回答の生成
- 回答の根拠となった参照ソースの一覧表示

## 使用する技術

ベクトル化と回答生成にはOllamaを利用する。

- 埋め込みモデル: `nomic-embed-text`
- 回答生成モデル: `llama3.1`（または軽量モデルの `phi3`）

## 想定する利用シーン

個人が手元に持つ資料（議事録・仕様書・マニュアルなど）を事前に取り込んでおき、後から自然文で内容を検索・質問したい場合に利用する。すべての処理をローカル環境で完結させるため、外部サービスに文書を送信する必要がない。
